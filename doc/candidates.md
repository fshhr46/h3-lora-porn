## 🔧 下载与预处理

### Step 1: 下载

```bash
# 用 yt-dlp 批量下载
yt-dlp -o 'data/raw/xvideos/%(id)s.%(ext)s' \
  https://www.xvideos.com/video.akvaai8ce7/slow_motion_20150301_175302
  # ... 逐个下载或写脚本

# 或使用 collect.py
python collect.py --source xvideos --keywords "bikini,lingerie,wet swimsuit" --count 15 --output data/raw
```

### Step 2: 预处理 - 静态图片（普通 LoRA）

```bash
python preprocess_enhanced.py --mode images \
  --input data/raw --output data/cropped \
  --fps 8 --resolution 512x512
```

### Step 2b: 预处理 - 时序序列（Temporal LoRA）

```bash
python preprocess_enhanced.py --mode temporal \
  --input data/raw --output data/temporal \
  --fps 8 --seq_length 8
```

### Step 3: 训练

```bash
# 普通 LoRA
python train_lora.py --data_dir data/cropped --output_dir output/models/lora

# 或 Temporal LoRA
python train_video_lora.py --mode temporal \
  --video_dir data/temporal --output_dir output/models/temporal
```
